# Online Photography Print Selling System

## 📌 Project Overview

The Online Photography Print Selling System is a web-based e-commerce platform that allows photographers to showcase and sell their photographs as physical prints.

Customers can browse photographs, select print specifications, add products to a cart, and place orders online. Photographers can manage their photographs, pricing, and print options, while administrators can manage users, products, and orders.

## 🎯 Objectives

- Provide an online platform for selling photography prints.
- Help photographers reach a wider customer base.
- Allow customers to easily browse and purchase photo prints.
- Provide different print sizes and options.
- Simplify product and order management.

## 👥 User Roles

### Customer
- Register and login
- Browse photographs
- View photo details
- Select print options
- Add items to cart
- Place orders
- Track orders

### Photographer
- Login
- Upload photographs
- Manage photographs
- Set prices
- Manage print options
- View orders

### Administrator
- Manage users
- Manage photographers
- Manage photographs
- Manage products
- Manage orders
