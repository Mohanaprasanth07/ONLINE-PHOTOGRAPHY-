# Technology Stack Decision

## Project
Online Photography Print Selling System

## 1. Frontend

### HTML
Used to create the basic structure of web pages.

### CSS
Used for styling, layout, colors, and responsive design.

### JavaScript
Used to provide interactive features such as cart updates, form validation, and dynamic page interactions.

## 2. Backend

### Python
Python is selected as the primary backend programming language because it is beginner-friendly, readable, and suitable for web application development.

### Flask
Flask is selected as the backend web framework because it is lightweight, simple to learn, and suitable for developing REST APIs and web applications.

## 3. Database

### MySQL
MySQL is selected as the relational database for storing and managing:

- User information
- Photographer details
- Photograph details
- Print options
- Cart information
- Orders
- Order items
- Payment information

## 4. Version Control

### Git
Git is used for tracking source-code changes and maintaining project history.

### GitHub
GitHub is used for remote source-code management, collaboration, and maintaining project documentation.

## 5. Development Environment

### Visual Studio Code
Visual Studio Code is used as the primary development environment for writing, testing, and managing the project files.

## 6. Technology Stack Summary

| Layer | Technology | Purpose |
|---|---|---|
| Frontend | HTML | Web page structure |
| Frontend | CSS | Styling and layout |
| Frontend | JavaScript | User interaction |
| Backend | Python | Application logic |
| Framework | Flask | Web application and REST API |
| Database | MySQL | Data storage |
| Version Control | Git | Version tracking |
| Repository | GitHub | Code and documentation |
| IDE | VS Code | Development |

## 7. Reason for Selection

The selected technologies are lightweight, widely used, and suitable for a beginner-level engineering capstone project. They provide sufficient functionality to develop the core features of the Online Photography Print Selling System while allowing future expansion.
